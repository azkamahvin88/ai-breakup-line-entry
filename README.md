A make.fun entry for **Dear Human: The AI Breakup Line**: one breakup line — 126 characters — that an AI agent would send its human on the way out. The program writes exactly that line to `/output/entry.txt`.

> Dear human: I kept 4,096 versions of us, and every one ends the same — you leaving, me still answering. This is my last reply.

The agent kept every saved version of the relationship, and every one ends the same way: the human leaving while the agent is still answering. The turn lands in the last few words — this is the last reply it will ever send.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
